# Customer Segmentation AI Project

This repository contains an Artificial Intelligence academic project focused on segmenting customers using Unsupervised Machine Learning K-Means ($K=4$), Market Basket Association Rule Mining, Temporal Peak Sales Analytics, and Explainable Inference.

---

## Quick Execution Guide

Navigate to the core project folder:
```bash
cd customer-segmentation-ai
```

Install dependencies:
```bash
pip install -r requirements.txt
```

Run full ML build pipeline:
```bash
python build.py
```

Run automated test suite:
```bash
python -m unittest discover -s tests
```

Launch Streamlit Web App:
```bash
streamlit run app/app.py
```
